Project Overview

SmartRevise AI is a comprehensive, intelligent learning ecosystem designed to revolutionize how students prepare for exams and master complex subjects. By combining traditional Machine Learning with modern Generative AI (LLMs), the platform provides personalized, data-driven study tools.

Efficient

Accelerate learning through automated summarization and extraction.

Personalized

AI recommendations based on your performance and weak areas.

Collaborative

Real-time study groups for peer learning and knowledge sharing.

Core Features

PDF Intelligence

Upload PDFs to automatically generate summaries, key points, structured notes, and practice MCQs. Uses TF-IDF and TextRank for fast, offline-capable analysis.

AI Tutor (RAG)

A persistent chat assistant powered by Gemini. It uses Retrieval-Augmented Generation (RAG) to answer questions based on your own notes, code, and syllabus.

Coding Assistant

Generate coding challenges based on specific topics. Receive AI-driven feedback and track your problem-solving progress.

Advanced Analytics

Visualize your study habits, quiz accuracy, and topic-wise mastery. Identify weak areas with data-driven insights.

ML Technologies & Algorithms

Technology Algorithm / Library Working Principle
Summarization TextRank (PageRank) Builds a graph of sentence similarities using TF-IDF and ranks them using the PageRank algorithm.
Keyword Extraction TF-IDF Vectorizer Evaluates how relevant a word is to a document in a collection by comparing frequency.
Topic Clustering K-Means Clustering Groups sentences into N clusters based on their vector space representation (using Scikit-Learn).
NER SpaCy / NLTK Named Entity Recognition identifies people, organizations, locations, and technical terms.
LLM Integration Gemini 1.5 Flash Generates high-impact summaries, structured JSON notes, and context-aware chat responses.
Similarity Cosine Similarity Measures the cosine of the angle between two vectors to determine how similar two sentences are.

ML Pipeline Architecture

1
Ingestion & Preprocessing

PDF extraction via PyPDF2. Text is cleaned, hyphenation fixed, and split into sentences using SpaCy.

2
Feature Engineering

Vectorization of text using TF-IDF. Extraction of Named Entities (NER) for knowledge boosting.

3
Logic Execution

Concurrent execution of TextRank for summaries, K-Means for clustering, and pattern matching for definitions.

4
LLM Augmentation (Hybrid Mode)

If API key is available, the engine sends processed chunks to Gemini for high-quality abstractive summaries and MCQ generation.

5
Output Structuring

Data is formatted into JSON objects and served to the frontend via Flask routes.
