Under the Hood: The ML Pipeline

Data Processing Flow

  1. Ingestion: PDF bytes are read and cleaned. Hyphenation at line breaks is fixed via regex.
  2. Segmentation: SpaCy splits the text into logical sentences while filtering out noise.
  3. Vectorization: TF-IDF calculates word importance across the document.
  4. Ranking: The TextRank algorithm (PageRank on sentences) identifies high-value content.
  5. Clustering: K-Means groups sentences into distinct "Topics" based on semantic similarity.
# Example of PageRank Logic in our Pipeline
def _pagerank(sim_matrix, damping=0.85):
  n = len(sim_matrix)
  norm = sim_matrix / sim_matrix.sum(axis=1)
  scores = np.ones(n) / n
  for _ in range(50):
    scores = (1-damping)/n + damping * norm.T.dot(scores)
  return scores

Feature Breakdown

Hybrid PDF Intelligence

Unlike standard tools, SmartRevise uses a Hybrid Approach. It first analyzes the PDF locally using Traditional ML for speed and cost-efficiency. If a Gemini API key is present, it "upgrades" the analysis to Abstractive mode, providing much more nuanced summaries and higher-quality MCQs.

AI Tutor with RAG

The AI Tutor is not just a chatbot. It implements Retrieval-Augmented Generation. When a user asks a question, the system searches the RevisionNote, CodeSubmission, and StudyRoadmap tables to find relevant context. This context is fed to Gemini, ensuring the answer is tailored to the student's actual study material.

Behavioral Analytics

The platform tracks Daily Streaks, Study Minutes, and Topic Performance. Using Chart.js, it visualizes "Weak Topics" (where MCQ scores are < 60%) and provides proactive "AI Recommendations" on the dashboard to guide the student's next move.

The End Result

A seamless, end-to-end educational platform that transforms static PDF documents into dynamic, interactive learning experiences. By bridging the gap between traditional data science and modern generative AI, SmartRevise AI empowers students to study smarter, not harder.
